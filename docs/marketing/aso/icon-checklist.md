# App Icon Checklist (ASO)

Use this checklist before uploading icon assets for any locale.

- [ ] Primary symbol remains recognizable at 48x48 and 64x64.
- [ ] Contrast is readable on both light and dark store backgrounds.
- [ ] No thin text that disappears at small sizes.
- [ ] No religious or medical claims in icon text.
- [ ] Visual style matches in-app brand (FutureSeer identity).
- [ ] iOS and Android icon variants are visually consistent.
- [ ] Exported sizes match App Store Connect and Play Console requirements.
- [ ] Final files are optimized PNGs and versioned by date.

## Naming convention

- `icon-master.png`
- `icon-ios-1024.png`
- `icon-android-512.png`
- `icon-foreground.png`
- `icon-background.png`
