# Gemstone Photos

This folder should contain realistic photos of the 9 Navaratna gemstones.

## Required Images

Place high-quality photos (PNG or JPG format, optimized for web) with these exact names:

- `ruby.png` - Ruby (Sun)
- `pearl.png` - Pearl (Moon)
- `red-coral.png` - Red Coral (Mars)
- `emerald.png` - Emerald (Mercury)
- `yellow-sapphire.png` - Yellow Sapphire (Jupiter)
- `diamond.png` - Diamond (Venus)
- `blue-sapphire.png` - Blue Sapphire (Saturn)
- `hessonite.png` - Hessonite Garnet (Rahu)
- `cats-eye.png` - Cat's Eye (Ketu)

## Recommended Sources

1. **GitHub Repositories:**
   - `tcm151/Gemstone-Classification` - Machine learning dataset with gemstone images
   - `hybchow/gems` - Gemstone classification project images
   - Verify licenses (MIT, CC BY, or public domain)

2. **Free Image Libraries:**
   - Unsplash (unsplash.com) - Search for gemstone names
   - Pexels (pexels.com) - Free stock photos
   - Pixabay (pixabay.com) - Free images

## Image Specifications

- Format: PNG or JPG
- Recommended size: 400x400px to 800x800px
- Optimize for web (compress before adding)
- Ensure images clearly show the gemstone color and characteristics
