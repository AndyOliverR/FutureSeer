# Support FutureSeer

FutureSeer is open-source research into **inspectable traditional divination** (chart engines, knowledge files, Ask the Seer). Funding keeps that work public and the live product running.

## Ways to support

1. **GitHub Sponsors** — [github.com/sponsors/AndyOliverR](https://github.com/sponsors/AndyOliverR) (button on the repo once the profile is published)
2. **Credits** — [futureseer.app/credits](https://futureseer.app/credits)
3. **Contact** — [futureseer.app/contact](https://futureseer.app/contact)

**What funding pays for:** chart-engine accuracy, traditional knowledge-file depth, and keeping [futureseer.app](https://futureseer.app) online.

## Maintainer: publish GitHub Sponsors (required)

[`.github/FUNDING.yml`](.github/FUNDING.yml) only *names* the account. The Sponsor button does **not** collect money until you publish a GitHub Sponsors profile.

1. Open [github.com/sponsors/signup](https://github.com/sponsors/signup) while logged in as **AndyOliverR**.
2. Complete country, tax, and payout details GitHub asks for (India-supported payouts depend on GitHub’s current list).
3. Publish a **public** sponsor profile with a short research pitch (inspectable Vedic/Western engines, knowledge files, live app).
4. Add **three tiers** in plain language, for example:
   - Keep the Seer online (hosting / inference)
   - Fund traditional knowledge files
   - Chart-engine accuracy (ephemeris / pipeline work)
5. Confirm the **Sponsor** button appears on [github.com/AndyOliverR](https://github.com/AndyOliverR) and on [FutureSeer](https://github.com/AndyOliverR/FutureSeer).
6. If the button is missing: profile is still a draft, payouts are incomplete, or GitHub is still reviewing — finish signup; do not expect FUNDING.yml alone to create a payout.

## Maintainer: profile discovery (GitHub UI)

These need a click in the browser (the API token here cannot update user bio or pinned repos):

1. **Bio** — [github.com/settings/profile](https://github.com/settings/profile). Replace the Moore quote as the *only* bio with something searchable (keep the quote on the profile README), for example:  
   `Building inspectable AI + traditional divination. FutureSeer (futureseer.app) and local-first VassalOps. Bangalore.`
2. **Pinned repositories** — on [github.com/AndyOliverR](https://github.com/AndyOliverR) click **Customize your pins** and pin **FutureSeer** then **VassalOps**.
3. **Social** — LinkedIn and X are already linked. Confirm they show under the profile sidebar.
4. Optional CLI (needs `user` scope): `gh auth refresh -h github.com -s user` then you can PATCH `/user` for bio.
