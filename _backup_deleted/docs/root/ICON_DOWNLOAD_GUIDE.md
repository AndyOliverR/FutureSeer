**Primary Source**: Reshot
**URL**: https://www.reshot.com/free-svg-icons/astrology/

**How to Download**:
1. Go to https://www.reshot.com/free-svg-icons/astrology/
2. Search for each planet icon individually:
   - Search: "sun icon" or "sun symbol"
   - Search: "moon icon" or "moon symbol"
   - Search: "mercury planet icon"
   - Search: "venus planet icon"
   - Search: "mars planet icon"
   - Search: "jupiter planet icon"
   - Search: "saturn planet icon"
   - Search: "uranus planet icon"

   - Click on the icon you like
   - Click "Download" button
   - Select "SVG" format
   - Save to: `c:\FutureSeer\public\icons\astrology\planets\`

**Alternative Sources** (if Reshot doesn't have all):

### 3. Numerology Number Icons (0-9, 11, 22, 33)

**Source**: Tabler Icons
**URL**: https://tabler.io/icons

1. Go to https://tabler.io/icons
2. Search for number icons or use the number library
3. Download individual number SVG icons:
   - Numbers 0-9: Search "number 0", "number 1", etc.
   - Or use their number/numeral category
4. Save to: `c:\FutureSeer\public\icons\numerology\pythagorean\numbers\`
   - Files: `0.svg`, `1.svg`, `2.svg`, ... `9.svg`
5. For master numbers (11, 22, 33):
   - Create combined number icons or use two-digit representations
   - Save to: `c:\FutureSeer\public\icons\numerology\pythagorean\numbers\master-numbers\`
   - Files: `11.svg`, `22.svg`, `33.svg`

**Alternative**: If Tabler doesn't have suitable number icons, you can:
- Use simple text-based SVG numbers
- Or use lucide-react Number component as fallback (already in code)

### 4. Aspect Icons (5 icons)

**Source**: Custom or Tabler Icons symbols

**Aspects needed**:
- Conjunction (circles overlapping or side-by-side)
- Sextile (60° angle symbol)
- Square (90° angle symbol - square shape)
- Trine (120° angle symbol - triangle)
- Opposition (180° - opposite lines or circles)

**How to Create/Download**:
1. **Option A - Tabler Icons**:
   - Search for "angle", "geometry", or similar symbols
   - Use geometric shapes that represent angles
   - Save to: `c:\FutureSeer\public\icons\astrology\aspects\`

2. **Option B - Simple Custom SVGs**:
   - Create simple geometric shapes using any vector editor
   - Or use the symbols: ⊙ (conjunction), △ (trine), □ (square), ⚹ (sextile), ☍ (opposition)
   - Convert to SVG format
   - Save to: `c:\FutureSeer\public\icons\astrology\aspects\`

**Files needed**:
- `conjunction.svg`
- `sextile.svg`
- `square.svg`
- `trine.svg`
- `opposition.svg`

**Save to**: `c:\FutureSeer\public\icons\astrology\western\aspects\`

## File Naming Convention

**Important**: All files should be lowercase with hyphens or lowercase only:

**Zodiac Signs**:
- ✅ `aries.svg`, `taurus.svg`, `gemini.svg`, etc.
- ❌ `Aries.svg`, `TAURUS.svg`

**Planets**:
- ✅ `sun.svg`, `moon.svg`, `mercury.svg`, etc.
- ❌ `Sun.svg`, `SUN.svg`

**Numbers**:
- ✅ `0.svg`, `1.svg`, `11.svg`, etc.
- ❌ `zero.svg`, `one.svg`

**Aspects**:
- ✅ `conjunction.svg`, `trine.svg`, `square.svg`
- ❌ `Conjunction.svg`, `TRINE.svg`
